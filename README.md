 Enterprise-Security-Software-Research-Security-Controls-Report
A research report examining enterprise security software and security controls, including their purpose, attack coverage, testing approaches, limitations, and representative products.

This repository contains my research report on different enterprise cybersecurity software and security controls used to protect networks, applications, endpoints, and organisational systems.

 About the Report:
The report explores how different security controls are designed to detect, prevent, or reduce different types of cyber threats.

The report covers:
* Network Firewalls
* Web Application Firewalls (WAF)
* Anti-Virus Software
* Network Proxy / Secure Web Gateway
* Endpoint Detection and Response (EDR)
* Vulnerability Patching / Patch Management
* Intrusion Detection and Prevention Systems (IDS/IPS)

For each security control, the report discusses what it is designed to protect against, what it may not cover, suitable testing approaches, example enterprise products, and important limitations.

 Purpose:
The purpose of this report is to understand how different enterprise security controls work together and why no single security product can protect an organisation from every type of threat.

The report also considers practical factors such as configuration, visibility, false positives, false negatives, testing, monitoring, and operational limitations.
